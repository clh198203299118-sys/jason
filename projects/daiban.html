代班通

乐山出租车代班信息平台 · 让找代班不再靠吼

↓

这是什么

代班通是一个面向乐山市出租车行业的代班信息撮合平台。 车主可以发布代班需求（找人来替班），驾驶员可以发布求职信息（找车来开）， 解决出租车行业里「车主找不到代班司机、司机找不到车开」的老大难问题。

覆盖乐山 8 家出租汽车公司：全星、联合、春秋、佛运、海棠、旅游、安达、公交。

为什么叫"代班通"

在出租车行业，车主有事请假或休假时需要找代班司机临时运营车辆， 而驾驶员没车开时需要找车来替班。 过去这种撮合全靠微信群喊、打电话问、同事互相介绍——效率低、覆盖窄、信息不对称。

「代班通」把这件事搬到线上：按公司、班次筛选，一键查找匹配， 让代班信息流通起来。名字里的「通」，就是信息通畅的意思。

核心功能

代班需求
车主发布代班信息：车牌号、班次（白班/夜班/长期）、时间范围、交接地址、联系方式。
求职信息
驾驶员发布求职信息：从业资格证号、期望班次、期望交接地点、联系方式。
多维度筛选
按公司、班次类型、关键词多条件筛选，快速找到匹配的代班或求职信息。
实名认证
驾驶员须上传从业资格证照片验证身份；车主须提供车牌和公司信息，确保信息真实可靠。
一键联系
登录后可查看完整联系方式，直接与发布方沟通，快速达成代班协议。
分班次管理
支持白班（6:00-18:00）、夜班（18:00-6:00）和长期代班三种模式，精准匹配运营时段。

技术栈

纯前端应用，HTML + CSS + JavaScript 原生实现，无需任何框架。 响应式设计，手机和电脑都能流畅使用。

支持浏览器：Chrome / Edge / Safari / Firefox · 移动端适配
